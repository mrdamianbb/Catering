1) NEXT_PUBLIC_TURNSTILE_SITE_KEY
   - publiczny Site Key z Cloudflare Turnstile

2) TURNSTILE_SECRET_KEY
   - Secret Key z Cloudflare Turnstile

NEXT_PUBLIC_SUPABASE_URL powinien już być w projekcie.
